1. Purpose and Build Rules
This document converts the PRD/SOW into implementation contracts. The goal is to prevent an AI coding agent from inventing core data models, security boundaries, AI behavior or publishing semantics.
PostgreSQL/Supabase is the durable source of truth.
Redis is transient: cache, queues, locks, rate limits and progress.
Qdrant is a derived retrieval index; never the source of truth.
Original manuscripts/assets are immutable.
AI produces validated suggestions/jobs; it does not silently overwrite canonical content.
Retailer compliance is deterministic and versioned; LLMs may explain findings but never certify compliance.
All async jobs are idempotent, retryable and observable.
Every tenant-sensitive operation is authorized server-side.
Claude Code works one bounded ticket at a time with tests and CI gates.
